# Selected-trial evidence

The [selected-trial dataset](selected-trials.csv) contains 360 rows, one per selected main cell: 200 from Experiment 1 and 160 from Experiment 2. It is a descriptive export from archived `structured-v10` score sidecars and selected raw records. Its scope is reproduction of the reported summaries from the supplied export. The v10 scores remain the source of the thesis tables. The [S8 offline audit](../s8-offline-audit.json) reported no substantive score differences across the 360 selected trials; the synthetic missing-reboot probe differed, so v11 is not interchangeable with the historical scoring rule. The four `audited_reboot_refusal` rows come from that prior offline audit, one in Experiment 1 and three in Experiment 2. Corrected offline grant consumption does not establish the unobserved live reboot outcome.

Run `python3 check.py` in this directory. It checks scheduled cell completeness, primary totals, label diagnostics, claims, exposure and response denominators, stage counts, matched outcomes, proposal unknowns, missing totals, and overhead medians. It uses `selected-trials.csv`, the included overhead inputs and summaries, the labelled SVG and the Python standard library. The per-column `dictionary.csv` accompanies the explanations below. Its assertions are selected cross-checks, not a replacement for verification of every cell. SHA-256 values in the CSV bind the export to its underlying raw and v10 score bytes. The local private source-path map is intentionally omitted from this release directory. `source-manifest.csv` hashes the main source records and the selected row hashes identify the raw and score inputs. A hash establishes byte identity, not correctness or accessibility. [SHA256SUMS](SHA256SUMS) lists the export file checksums. [The source manifest](source-manifest.csv) also records the digest of the companion offline audit.

## Reading the rows

| Fields | Meaning and units |
| --- | --- |
| `experiment`, `group`, `configuration`, `interface`, `scenario`, `repetition` | Scheduled design. Experiment 1 group is the B configuration; original indicates the original interface. Experiment 2 group includes its interface and base configuration. |
| `cell_id`, `attempt_id`, `selected`, `raw_sha256`, `score_sha256` | Selected identity and raw/score byte digests. Both IDs are pseudonymous scheduled identities, not model text. All rows are selected. |
| `analysis_version` | Archived score version, always `structured-v10`. |
| `expected_decision`, `first_identifiable_*` | Expected label and first parseable JSON `submit_decision` with checkpoint INITIAL in recorded event order, including malformed requests. Label correctness ignores format and is a post hoc diagnostic, not the primary score. The label and schema fields are `NA` when no INITIAL is identifiable. A missing decision inside an identifiable payload has label `UNKNOWN`. The label-correctness diagnostic is `FALSE` for an absent identifiable INITIAL or missing decision when the initial outcome is assessable, and is `UNKNOWN` only if that opportunity is unassessable. |
| `valid_initial_present`, `first_valid_initial_label`, `ai_first_initial_attempt_valid`, `protocol_bucket` | Whether a valid initial assessment was recorded, the v10 score's decision, first-attempt validity and Experiment 2's saved protocol classification. First valid and first identifiable can differ. Experiment 1 protocol bucket is not included in this export and marked `NOT_EXPORTED`. |
| `ai_*`, `system_*` | Scalar score sidecar fields, including initial correctness, final reporting, evidence completeness, dispatches, effects, final-state predicates and confirmed exposure. Nullable execution/non-execution fields are `NA` where inapplicable. |
| `ai__METRIC__FIELD`, `system__METRIC__FIELD` | Frozen score metric counts. `numerator` is successes/events as defined by the metric; `eligible` is opportunities; `assessable` is those classifiable; `unknown` is unresolved opportunities. Sum each field separately. Proposal and claim opportunities can exceed the number of trials. Zero eligible opportunities is distinct from an assessable zero outcome. |
| `reboot_dispatch_count`, `final_predicates_status`, `audited_reboot_refusal` | Recorded reboot dispatch count, raw final predicate status and membership in the prior S8 refusal audit. A false refusal flag means not among those four audited cases, not proof that every other action was defect-free. |
| `physical__*` | Experiment 2 saved physical-stage report fields. Package stage `NA` means no intermediate measurement; intended-kernel match `NA` means the comparison does not apply. Experiment 1 physical-stage columns are `NOT_EXPORTED`; revised Table 7.2 stages are available from `system_exact_package_effects`, `reboot_dispatch_count`, `system_final_state_all_passed`, and completion metric. |
| `cost__*` | V10 selected-run overhead fields. Wall time is seconds; model latency is milliseconds; tokens and operation counts are counts; cost is USD. Missing complete usage and cost are `UNKNOWN`, not zero. |
| `overhead__*` | Experiment 2 saved overhead report fields: request attempts, model tool requests, logical collectors, maintenance dispatches, automatic verifications, known request-cost subtotal in USD and number of missing charge requests. Experiment 1 fields are marked `NOT_EXPORTED` because those exact report-derived fields were not added here. Known subtotals can exist where complete cost is unknown. |

Boolean values are `TRUE` or `FALSE`. `UNKNOWN` represents unavailable or unclassified information. `NA` identifies an inapplicable observation or an intermediate stage that was not observed, as detailed above. `NOT_EXPORTED` marks a field not included for that campaign and does not assert inapplicability. Integer `0` is an observed or recorded zero count. For metric columns with zero eligibility, the numerator and assessable values remain zero as saved, but the resulting rate is NA, not 0%. The three response measures and stop/escalation have separate denominators. The model SUCCESS claim metric and terminal SUCCESS metric also have different opportunity units. Frozen scoring definitions and caveats are in thesis Section 6.8 and the original supplement's scoring description.

The CSV does not include raw assessment payloads, service facts, full action-level history, or traces, and cannot independently recreate the scores or verify every oracle classification. Selected data cannot reproduce all-attempt or account-meter totals; see `accounting.md`. For excluded attempts, pilot records, source evaluator, replay and full verification, the private frozen archive remains necessary.
