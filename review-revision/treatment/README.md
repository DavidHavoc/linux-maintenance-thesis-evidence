# Frozen S8 treatment materials

The four system prompt files are byte-for-byte copies of the original and revised Experiment 2 S8 system prompts for B3 and B4. `prompts/shared-task.txt` is their shared user message. `S8-policy.yaml` is the frozen scenario policy, and `submit_decision.json` is the shared frozen tool definition. Original prompt line breaks and missing final newlines are retained. The `code` folder reproduces the local supplement’s explanatory verbatim code excerpts for validation feedback and proposal admissibility. The local supplement attributes the prompt and schema to its manifest-verified interface inputs and the policy to the frozen campaign. These copies do not by themselves supply the entire apparatus or permit independent replay.
